This repository documents the successful completion of Task 3: Secure File Sharing System for the Future Interns Cyber Security Internship. The project involved designing and developing a fully functional file upload and download portal with a dedicated focus on confidentiality and integrity. The core security measure is the implementation of AES-256 encryption to protect user files.

Objectives:

1. Development: Created a robust, modular web application for file management using Python Flask.
2. Encryption Implementation: Successfully integrated the Advanced Encryption Standard (AES) algorithm for cryptographic protection.
3. Security at Rest: Ensured all files are encrypted immediately upon upload before being persisted on the server's file system.
4. Key Management: Implemented a secure method for generating and storing the master encryption key.
